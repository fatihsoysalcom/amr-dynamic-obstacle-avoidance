# AMR Dynamic Obstacle Avoidance

This Python script simulates an Automatic Mobile Robot (AMR) navigating a grid. It demonstrates how an AMR dynamically avoids a moving obstacle while moving towards a target. This highlights the AMR's ability to sense its environment and re-plan its path in real-time, a key differentiator from fixed-path Automated Guided Vehicles (AGVs).

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt, navigate to the directory where you saved the file, and run `python main.py`.
